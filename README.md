# 4КРУГА

Каталог запчастей и комплектующих для электросамокатов.

[Открыть сайт](https://loginnok.github.io/4kruga-client-preview/)

## Каталог

- Поиск по названию и артикулу.
- Фильтры по категории, бренду, модели и цене.
- Карточки товаров с фотографиями, описаниями и доступными характеристиками.
- Корзина с сохранением выбранных товаров в браузере.
- Информация о ремонте, доставке и контакты магазина.
- Адаптивная версия для телефонов и компьютеров.

Названия, фотографии и сведения о товарах получены с [4kruga.ru](https://4kruga.ru/). Изображения хранятся в проекте. Цены и сведения о наличии относятся к моменту загрузки каталога; перед покупкой их необходимо уточнить у магазина. Совместимость указана только там, где она подтверждена исходными данными.

## Версия на GitHub Pages

Публичная версия предназначена для просмотра каталога и согласования сайта. Поиск, фильтры, страницы товаров и корзина работают в браузере.

Приём заказов, онлайн-оплата и отправка заявок на ремонт в этой версии не подключены. Реальные заказы магазину не передаются. Административная часть недоступна.

[Размещение на GitHub Pages](GITHUB_PAGES.md) · [Настройка режима просмотра](CLIENT_PREVIEW.md)

## Локальное приложение

Серверная версия использует Node.js, TypeScript, PostgreSQL, Prisma и Zod. В обычном локальном режиме доступны сохранение корзин, заказов и заявок в базе, а также защищённое управление товарами и заказами. Оплата через платёжного провайдера не подключена.

Режим `CLIENT_PREVIEW` использует отдельную базу для просмотра каталога и блокирует создание заказов, отправку заявок, административные и служебные API.

### Запуск на Windows

Требуется Node.js 24.x.

```powershell
npm ci
npm run setup:local
npm run preview:setup
npm run build
npm run preview
```

Адрес: [http://localhost:3000](http://localhost:3000). Если порт уже занят, сначала остановите ранее запущенный экземпляр приложения.

Для обычного локального режима после настройки используется `npm start`. Настройки подключения задаются в переменных окружения; пример находится в `.env.example`. Файлы `.env`, содержимое `.state` и резервные копии базы не следует добавлять в репозиторий.

### Проверки

```sh
npm run typecheck
npm run lint
npm run build
npm test
```

Тесты работают с отдельными тестовыми базами. Параметры запуска и ограничения описаны в документации проекта.

## Структура

- `src/` — сервер, API и проверки входных данных.
- `public/` — интерфейс, стили и фотографии.
- `prisma/` — схема, миграции и каталог.
- `scripts/` — настройка, сборка и запуск.
- `tests/` — проверки приложения.

Для полноценного интернет-магазина требуется серверное размещение с HTTPS, рабочей базой данных и согласованными интеграциями. GitHub Pages размещает только версию для просмотра.
