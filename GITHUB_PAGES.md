# Публичный просмотр 4КРУГА на GitHub Pages

Адрес: https://loginnok.github.io/4kruga-client-preview/.

Это публичный просмотр существующего дизайна C: 41 реальный товар, 67 локальных фотографий, цены и наличие по снимку 4kruga.ru. Каталог, поиск, фильтры, сортировка, пагинация, галереи и переходы работают в браузере по опубликованному снимку. Новые заказы, заявки, оплата и административные действия недоступны. Сайт не является действующим магазином 4kruga.ru.

GitHub Pages обслуживает HTML/CSS/JavaScript и не запускает Node.js/PostgreSQL. Исходный сервер и полноценные локальные функции магазина сохранены отдельно от этого режима. Перед подключением приёма заказов нужен отдельно размещённый и проверенный backend.

## Сборка

Нужен Node.js 24.x. В корне проекта:

```sh
npm run build:pages
```

Команда не обращается к рабочей БД и не копирует env, .state, заказы, сессии или администраторов. Она создаёт docs/ из существующих public/ и prisma/official-catalog.json. В каждую страницу добавляются базовый путь /4kruga-client-preview и явный режим статического просмотра. Генерируются отдельные index.html для каталога, 41 товара и информационных страниц, чтобы прямое открытие и перезагрузка работали без серверного роутинга.

public/catalog-reader.js читает опубликованный JSON. Он выполняет реальные операции поиска/фильтрации снимка, а не возвращает заранее подготовленные результаты. Все запросы изменения и неизвестные приватные ресурсы отклоняются. Отсутствующий backend не имитируется. На GitHub Pages нет действующих маршрутов заказов или административных API.

## Обновление

Сначала сверить и обновить исходные материалы с разрешённого сайта, выполнить тесты, затем npm run build:pages. Публикация — commit docs/ в main и push в публичный Loginnok/4kruga-client-preview. Источник GitHub Pages: main, /docs. Встроенная сборка GitHub Pages должна завершиться со статусом built перед передачей ссылки.

Не изменять базовый путь без смены URL репозитория. Не добавлять рабочие БД, исходные env или секреты в docs/. Старый защищённый серверный CLIENT_PREVIEW сохраняется как отдельный вариант размещения на VPS; он не является механизмом авторизации GitHub Pages.

## Доступ и данные

По указанию владельца сайт открыт без пароля. GitHub обрабатывает IP и технические данные подключения согласно своей политике: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement. Приложение не собирает контактные данные через формы, не устанавливает cookies корзины и не подключает стороннюю аналитику. Публично доступны только разрешённые материалы каталога.

## Проверки перед выпуском

```sh
npm run typecheck
npm run lint
npm run build
npm test
npm run build:pages
```

38 автоматических тестов прошли, включая 6 проверок статического каталога. Проверены поиск, совместные фильтры, цены, наличие, сортировка, пагинация, запрет записи и отсутствие чужих/приватных маршрутов. Локальная браузерная проверка Pages: главная, каталог и товар на 320, 375, 390, 768, 1024 и 1440 px — без переполнения и не загруженных видимых фотографий. Финальная публичная проверка и состояние deployment сохраняются в отчёте владельца после публикации.
